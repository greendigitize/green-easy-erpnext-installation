# Changelog

## 3.0.46
- Removed all Saudi Riyal and currency customization from the base installer.
- Removed the Saudi Riyal compatibility font installation from the base installer.
- Restored the installer to a clean ERPNext/Frappe setup with no currency customization.
- Preserved the v15/v16, OS-aware runtime, MariaDB, Node/npm, Redis, permissions, Payments, HRMS, Supervisor, Nginx, and health-check fixes from previous builds.

## 3.0.42
- Removed legacy ERPNext/Frappe v13 and v14 support.
- Installer now focuses on ERPNext v15 and v16 on Ubuntu 24.04 and Debian 13 profiles.

## v3.0.46

- Removed dependency on Bench-generated Redis template configs during temporary installation.
- Temporary Redis queue/cache daemons now always bind to the exact dynamically selected ports.
- Production Redis configuration remains generated by `bench setup redis`.
